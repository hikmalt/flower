# 🌸 3D Interactive Blooming Flowers

An interactive, romantic 3D blooming flower bouquet and enchanted meadow island built with CSS 3D Transforms, Canvas particles, and Web Audio API.

## ✨ Features
- **Full 360° Volumetric 3D Bouquet**: Touch/mouse drag orbit to view blooming flowers, wrapping cone, and ribbons from all angles.
- **Enchanted Circular Meadow Garden**: Radial mini grass beds surrounding the bouquet base in 3 concentric rings.
- **Automated Atmosphere**:
  - Romantic pentatonic music box audio synthesized via Web Audio API.
  - Automatic color theme cycling (Sunset, Sakura Dream, Cosmic Galaxy, Golden Emerald).
  - Falling flower petals, glowing fireflies, twinkling stars, and frequent shooting meteors.
- **Ultra-lightweight & Responsive**: Zero-lag 60–120 FPS performance on mobile, tablet, and desktop (`100dvh`).
- **Intuitive Controls**:
  - **Drag / Swipe**: 360° orbital rotation.
  - **Double Click / Tap**: Smoothly reset view back to front.
  - **Top-right Button**: Mute / Unmute music box.

## 🚀 Usage / Deployment
Simply open `index.html` in any modern web browser or deploy directly with **GitHub Pages**!
